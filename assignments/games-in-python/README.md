
# 📘 Assignment: Games in Python

## 🎯 Objetivo

Construa um jogo da Forca em Python para praticar manipulação de strings, listas, seleção aleatória, loops, condicionais e entrada de dados.

## 📝 Tarefas

### 🛠️ Preparar a palavra e o progresso do jogo

#### Descrição
Crie a estrutura inicial do jogo: selecione aleatoriamente uma palavra de uma lista e mostre ao jogador quais letras ainda estão ocultas.

#### Requisitos
O programa concluído deve:

- Manter uma lista predefinida com pelo menos cinco palavras.
- Selecionar uma palavra aleatoriamente para cada partida.
- Exibir uma posição oculta para cada letra da palavra, por exemplo, `_ _ _ _`.

### 🛠️ Implementar os palpites e o encerramento da partida

#### Descrição
Permita que o jogador tente adivinhar letras até revelar a palavra ou esgotar o limite de tentativas incorretas.

#### Requisitos
O programa concluído deve:

- Solicitar palpites de uma letra e atualizar todas as posições correspondentes na palavra.
- Contabilizar e exibir as tentativas incorretas restantes.
- Encerrar a partida quando a palavra for adivinhada ou não houver tentativas restantes.
- Exibir uma mensagem indicando vitória ou derrota e revelar a palavra escolhida.
